전국 초·중·고등학교 급식 식단
쉽고 빠르고 명확하게 확인

Meal Service는 전국 초·중·고등학교의 식단표, 영양성분, 알레르기 유발 정보를 실시간으로 조회하고 편리하게 관리할 수 있도록 제작된 웹 애플리케이션입니다.

전국 12,000+ 학교 지원
1~19번 알레르기 정보 표시
모바일/PC 완벽 최적화

웹사이트 주요 기능 요약

학생, 학부모, 교직원이 실생활에서 매일 활용할 수 있는 핵심 편의 기능

실시간 학교 검색

전국 교육청 관할 초·중·고등학교를 실시간 검색으로 간편히 등록하고 당일 식단을 즉시 확인할 수 있습니다.

알레르기 유발 정보 안내

난류, 우유, 메밀, 땅콩, 대두 등 19가지 식약처 고시 알레르기 유발 번호를 식단 메뉴 옆에 명확히 표기합니다.

일자별/주간 식단 뷰er

오늘의 급식뿐만 아니라 내일, 이번 주 전체 식단을 달력과 슬라이드 형태로 편리하게 미리 파악할 수 있습니다.

자주 찾는 학교 즐겨찾기

내 학교나 자녀의 학교를 저장하여 매번 재검색 없이 웹페이지 재방문 시 즉시 급식표를 로딩합니다.

영양 성분 상세 정보

열량(kcal), 탄수화물, 단백질, 지방, 비타민 등 급식 한 끼의 상세 영양 정보 정보를 투명하게 전달합니다.

기술 스택 및 구조 요약

  • 데이터 연동 (NEIS Open API): 나이스 교육정보 개방 포털의 `hub.neis.go.kr` API를 이용해 공공데이터 수집
  • 배포 환경 (Vercel): Vercel의 Edge Network 기반 글로벌 CDN 배포로 높은 접근성과 빠른 속도 제공
  • 반응형 UI & 웹 표준: 모바일 스마트폰, 태블릿, PC 브라우저 등 디바이스에 구애받지 않는 반응형 레이아웃
